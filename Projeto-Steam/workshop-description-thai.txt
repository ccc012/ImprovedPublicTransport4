[h1]Improved Public Transport 4[/h1]
[b]One mod instead of fifteen.[/b] Full control of transit lines: fleet, vehicles, stops, fares. Small mods unified.
[b]เวอร์ชัน 4.8.9[/b] · สร้างสำหรับเกมเวอร์ชัน 1.21.1-f9

[h1]ทำไมถึงมีโมดนี้[/h1]
Transit maintenance hit [b]-42,000,000,000[/b] - two mods resizing fleets over each other. This mod centralizes control.
[hr][/hr]
[h1]คุณทำอะไรได้บ้าง[/h1]
[h2]ควบคุมไลน์ได้ทุกเส้น[/h2]
Every line type: [b]fleet control[/b], [b]vehicle selection[/b], [b]individual edits[/b], [b]depot choice[/b].
[h2]แก้ปัญหารถเกาะกลุ่ม[/h2]
Three anti-bunching levels: [b]Disabled[/b], [b]Prudent[/b], [b]Realistic[/b]. [b]Express[/b] skips empty stops.
[h2]กำหนดค่าโดยสารเอง[/h2]
Price each type in [b]Economy[/b], with [b]day/night pricing[/b].
[h2]เห็นสิ่งที่เกิดขึ้น[/h2]
[b]Stop info[/b], [b]vehicle route panel[/b], [b]auto colours/names[/b], [b]airport flight board[/b].
[h2]ทำความสะอาดเครือข่าย[/h2]
[b]Bulk line deletion[/b], [b]elevated stops[/b], [b]unstucker[/b] for stuck vehicles.
[h2]4.8.9: สวิตช์หลัก ฮอตคีย์ โอเวอร์เลย์ปลายทาง[/h2]
ควบคุมและ hardening [b]สวิตช์หลักหกตัว[/b] (ปิดเป็นค่าเริ่มต้น) [b]ฮอตคีย์ 13 ตัวผูกใหม่ได้[/b] ปลายทางผู้โดยสารสร้างใหม่เป็นโอเวอร์เลย์แผนที่ (Experimental) Intercity คืน prefab เมื่อปิด Train Display: ช่วงตามโปรไฟล์ แท็บ Compat รายละเอียดบน GitHub
