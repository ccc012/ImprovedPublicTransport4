[h1]Improved Public Transport 4[/h1]
[b]โมดเดียวแทนสิบห้าโมด[/b] ควบคุมไลน์ขนส่งได้เต็มที่: ขนาดขบวน ประเภทยานพาหนะ ป้ายรถ ค่าโดยสาร รวมโมดเล็กๆ เข้าด้วยกัน
[b]เวอร์ชัน 4.8.9[/b] · สร้างสำหรับเกมเวอร์ชัน 1.21.1-f9

[h1]ทำไมถึงมีโมดนี้[/h1]
ค่าบำรุงรักษาขนส่งพุ่งทะลุ [b]-42,000,000,000[/b] — สองโมดแก้ไขขนาดขบวนพร้อมกันและเขียนทับกันเอง โมดนี้แก้ปัญหาขัดแย้งโดยรวมการควบคุมไว้ที่เดียว
[hr][/hr]
[h1]คุณทำอะไรได้บ้าง[/h1]
[h2]ควบคุมไลน์ได้ทุกเส้น[/h2]
ไลน์ทุกประเภทมี: [b]ควบคุมขบวน[/b] (กำหนดเองหรือตามงบประมาณ), [b]เลือกยานพาหนะ[/b], [b]แก้ไขทีละรายการ[/b] และ [b]เลือกอู่[/b]
[h2]แก้ปัญหารถเกาะกลุ่ม[/h2]
สามระดับต้านการเกาะกลุ่ม: [b]ปิดใช้[/b] (วานิลลา), [b]ระมัดระวัง[/b] (ระยะห่าง), [b]สมจริง[/b] (ช่วงเวลาจริง) โหมด [b]ด่วน[/b] ข้ามป้ายที่ไม่มีคน
[h2]กำหนดค่าโดยสารเอง[/h2]
ตั้งราคาแต่ละประเภทขนส่งในแผง [b]เศรษฐกิจ[/b] พร้อมตัวเลือก [b]ราคากลางวัน/กลางคืน[/b] ราคากระตุ้นความต้องการตามธรรมชาติ
[h2]เห็นสิ่งที่เกิดขึ้น[/h2]
[b]ข้อมูลป้าย[/b] (ผู้โดยสาร ยานพาหนะ ความแออัด), [b]แผงเส้นทางยานพาหนะ[/b] (อินเทอร์เฟซแบบปรับได้สด), [b]สี/ชื่อไลน์อัตโนมัติ[/b] เพื่อความชัดเจน, [b]กระดานเที่ยวบินสนามบิน[/b] (ขาเข้า/ขาออก)
[h2]ทำความสะอาดเครือข่าย[/h2]
[b]ลบไลน์เป็นชุด[/b] (ตามประเภท ยืนยันแล้ว), [b]วางป้ายยกพื้น[/b] และ [b]ตัวปลดรถติด[/b] สำหรับยานพาหนะที่ค้างอยู่
[h2]4.8.9: สวิตช์หลัก, ปุ่มลัด, เขียนทับเลเย้อร์ปลายทางใหม่[/h2]
ไม่ใช่โมดที่ดูดซับมาใหม่ — เป็นการควบคุมและเสริมแข็ง [b]สวิตช์หลักหกฟีเจอร์[/b] (แยกกลุ่ม, งบประมาณ, สีไลน์อัตโนมัติ, จอแสดงรถไฟ, ตัวแก้ไขยานพาหนะ, ป้ายและสถานี): ปิดโดยค่าเริ่มต้น; ปิดสวิตช์ใดจะล็อกฟีเจอร์ย่อยและหยุดแพตช์ที่เกี่ยวข้อง [b]ปุ่มลัดที่กำหนดใหม่ได้สิบสามปุ่ม[/b] (แผงไลน์, แยกกลุ่ม, คัดลอก/วาง, ตัวแก้ไขยานพาหนะ, Flight Tracker, ยานพาหนะก่อนหน้า/ถัดไป, และอื่นๆ) [b]การแสดงปลายทางผู้โดยสาร[/b] สร้างใหม่เป็นเลเย้อร์แผนที่ที่สะอาด (วงกลม + จำนวน); พอร์ตแผงเก่าถูกลบออก — ยังเป็น [b]ทดลอง, ปิดโดยค่าเริ่มต้น[/b] [b]Intercity Bus Control[/b] คืนพรีแฟบสถานีเดิมเมื่อปิดใช้ [b]จอแสดงรถไฟ[/b]: ช่วงเวลาตายตัวตามโปรไฟล์ประสิทธิภาพ, เมนูดรอปดาวน์ขอบเขต (เลือกแล้ว / บุคคลที่หนึ่ง / ทั้งสอง), ตรวจจับ First Person Camera - Continued ความปลอดภัยเธรดและเสริมแข็งข้อมูลบันทึก; การหาเส้นทางรถด่วนล้มเหลวแบบเปิด [b]แท็บความเข้ากัน[/b] แสดงโมดเพื่อนที่แนะนำพร้อมลิงก์เวิร์กช็อป ยานพาหนะเวิร์กช็อปที่ทำเครื่องหมาย Placement.Procedural จะไม่ถูกซ่อนจากรายการยานพาหนะอีกต่อไป บันทึกการเปลี่ยนแปลงทางเทคนิคเต็มรูปแบบบน GitHub

[h1]ภาษา[/h1]
ตามภาษาของเกม หรือเลือกเองในตัวเลือก ภาษาอังกฤษและโปรตุเกสได้รับการอัปเดตเต็มรูปแบบในทุกเวอร์ชัน; ภาษาอื่นๆ ตามมาเป็นชุดและอาจล้าหลังหนึ่งสองเวอร์ชันในข้อความใหม่ — จะใช้ภาษาอังกฤษแทนในระหว่างนั้น

[h1]เริ่มต้น[/h1]
