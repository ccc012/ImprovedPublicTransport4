[h1]Improved Public Transport 4[/h1]
[b]ม็อดเดียวแทนสิบห้าม็อด.[/b] ควบคุมระบบขนส่งสาธารณะได้เต็มรูปแบบ: จำนวนยานพาหนะ, ประเภทยานพาหนะ, ป้ายหยุด, ค่าโดยสาร. รวมม็อดเล็ก ๆ ไว้ในที่เดียว.
[b]Version 4.8.8[/b] · Built for game version 1.21.1-f9

[h1]ทำไมม็อดนี้ถึงมีอยู่[/h1]
ค่าบำรุงรักษาระบบขนส่งพุ่งสูงถึง [b]-42,000,000,000[/b] — ม็อดสองตัวปรับจำนวนยานพาหนะของตัวเองอย่างอิสระและเขียนทับกันเอง. ม็อดนี้แก้ความขัดแย้งโดยรวมการควบคุมไว้ที่เดียว.
[hr][/hr]
[h1]คุณทำอะไรกับมันได้บ้าง[/h1]
[h2]ควบคุมทุกสายได้อย่างเต็มที่[/h2]
สายทุกประเภทได้รับ: [b]ควบคุมจำนวนยานพาหนะ[/b] (ปรับเองหรือตามงบประมาณ), [b]เลือกยานพาหนะ[/b], [b]แก้ไขทีละคัน[/b], และ [b]เลือกอู่[/b].
[h2]แก้ปัญหารถกระจุกตัว[/h2]
ระดับกันรถกระจุกตัวสามระดับ: [b]Disabled[/b] (เวอร์ชันเดิม), [b]Prudent[/b] (เว้นระยะ), [b]Realistic[/b] (ช่วงเวลาจริง). โหมด [b]Express[/b] ข้ามป้ายที่ว่าง.
[h2]กำหนดค่าโดยสารของคุณเอง[/h2]
ตั้งราคาการขนส่งแต่ละประเภทในแผง [b]Economy[/b] พร้อมตัวเลือก [b]ราคากลางวัน/กลางคืน[/b]. ราคากระตุ้นความต้องการอย่างเป็นธรรมชาติ.
[h2]ดูว่ากำลังเกิดอะไรขึ้น[/h2]
[b]ข้อมูลป้ายหยุด[/b] (ผู้โดยสาร, ยานพาหนะ, ความแออัด), [b]แผงเส้นทางของยานพาหนะ[/b] (โอเวอร์เลย์สดที่ปรับแต่งได้), [b]สีและชื่อสายอัตโนมัติ[/b] เพื่อความชัดเจน, [b]กระดานเที่ยวบินของสนามบิน[/b] (ขาเข้า/ขาออก).
[h2]จัดระเบียบเครือข่ายของคุณ[/h2]
[b]ลบสายเป็นกลุ่ม[/b] (ตามประเภท, ยืนยันก่อนลบ), [b]วางป้ายบนยกระดับ[/b], และ [b]unstucker[/b] สำหรับยานพาหนะที่ติดค้าง.
[h2]4.8.8: การล้างบั๊กจากการเล่นจริง[/h2]
นี่ไม่ใช่การอัปเดตฟีเจอร์ — ทุกการแก้ไขด้านล่างมาจากการเล่น 4.8.7 จริง ๆ แล้วรายงานสิ่งที่พัง. [b]การกำหนดเส้นทางของยานพาหนะ[/b] แก้แล้ว (รถบัสเคยชิดขอบถนนนอกป้ายและทะลุผ่านพื้นสะพาน; แพตช์การขึ้นรถแบบต่อคันอาจส่งรถบัสกลับรถก่อนกำหนด). [b]โอเวอร์เลย์จุดหมายของผู้โดยสาร[/b]: พบและแก้ความขัดแย้งของ Harmony patch จริง แต่การทดสอบยังแสดงว่าไอคอน/แผงไม่แสดงอย่างน่าเชื่อถือ — จึงยังคง [b]ปิดตามค่าเริ่มต้น, Experimental[/b]. [b]ช่องทำเครื่องหมายควบคุมงบประมาณ[/b] ไม่ถูกยกเลิกเองทันทีที่คุณติ๊กอีกต่อไป. [b]การกำหนดเส้นทางอู่[/b] แก้แล้วสำหรับอาคารที่ให้บริการสองอย่างพร้อมกัน. เพิ่มตัวป้องกันการคราฟต์ของเกมเวอร์ชันเดิมที่เกิดกับเซฟที่เสียหายบางประเภท (ไม่ใช่บั๊กของเรา — ตัวป้องกันแค่หยุดไม่ให้มันล้มทั้งซิมูเลชัน). ฉลากตัวเลือกหลายรายการเปลี่ยนชื่อเพื่ออธิบายว่ามันทำอะไรแทนที่จะตั้งตามชื่อม็อดต้นทาง (เครดิตยังอยู่ที่หน้านี้และในซอร์สโค้ด). changelog ทางเทคนิคฉบับเต็มอยู่บน GitHub ตามลิงก์ด้านล่าง.

[h1]ความต้องการของระบบและความเข้ากันได้[/h1]

[h1]ภาษา[/h1]
ใช้ตามภาษาในเกมของคุณ หรือเลือกในตัวเลือก. ภาษาอังกฤษและภาษาโปรตุเกสอัปเดตครบถ้วนทุกเวอร์ชัน; ภาษาอื่น ๆ อัปเดตเป็นชุดและอาจล่าช้า 1–2 เวอร์ชันสำหรับข้อความใหม่ — จะแสดงเป็นภาษาอังกฤษชั่วคราวในระหว่างนั้น.
[hr][/hr]
[h1]การเริ่มต้นใช้งาน[/h1]
สมัครรับ [b]Harmony[/b], ยกเลิกเวอร์ชันแยก, เปิดใช้งาน IPT4. ตัวเลือก: [b]การตั้งค่า → การตั้งค่าม็อด → Improved Public Transport 4[/b]. ค่าโดยสาร: แผง [b]Economy[/b]. [b]เซฟเดิมใช้ได้[/b].
[hr][/hr]
[h1]ความเสถียร[/h1]
เสถียร. บั๊กค่าบำรุงที่พุ่งไม่หยุดแก้แล้ว; เซฟที่เสียหายซ่อมอัตโนมัติ. [b]สำรองเซฟไว้เสมอ[/b]. หากพบปัญหา ให้รายงาน [i]สิ่งที่คุณกำลังทำ[/i] และแนบ:
[code]%LOCALAPPDATA%\Colossal Order\Cities_Skylines\Cities_Data\output_log.txt[/code]
แค่บอกว่า “ใช้ไม่ได้” อย่างเดียวไม่เพียงพอสำหรับการวินิจฉัย.
