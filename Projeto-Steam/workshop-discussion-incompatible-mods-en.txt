[h1]Known Incompatible & Absorbed Mods[/h1]

Running IPT4 alongside mods that patch the same game code will cause conflicts, broken UI, or duplicated logic. This list is grouped by why, with a short note only where a specific mod needs one.

[hr][/hr]

[h2]Critical Incompatibilities[/h2]
Do [b]NOT[/b] use IPT4 alongside these. They aggressively modify the same core transit and vehicle-assignment data IPT4 owns — running them together will break your transport network, not just look wrong:

[url=https://steamcommunity.com/sharedfiles/filedetails/?id=424106600]Improved Public Transport (Original, 2015)[/url] · [url=https://steamcommunity.com/sharedfiles/filedetails/?id=928128676]Improved Public Transport 2[/url] · [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3690061052]Improved Public Transport 3[/url] — the three earlier generations IPT4 forks from and replaces entirely.
[url=https://steamcommunity.com/sharedfiles/filedetails/?id=1312767991]Transport Lines Manager[/url] · [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3007903394]Transport Lines Manager (alt listing)[/url] · [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2888964436]Improved Transport Manager[/url] — same category of function as IPT4 (per-line budget/fleet control); Improved Transport Manager is Klyte45's unfinished TLM/IPT2 successor, never left beta.

[hr][/hr]

[h2]Known Minor Interaction Risk (no need to unsubscribe)[/h2]
Found by code review, not yet reported by a player — listed here so it's public before it bites someone. No action needed unless you hit the specific symptom below:

[url=https://steamcommunity.com/sharedfiles/filedetails/?id=2804719780]Transfer Manager CE[/url] — both mods patch the game's own [i]CreateIncomingVehicle[/i]/[i]CreateOutgoingVehicle[/i] airport-terminal methods. In the narrow case where you have TMCE's [b]"Force Passenger Plane Spawn At Gate"[/b] option enabled AND you've disabled IPT4's "accept intercity" toggle on that specific airport gate, IPT4's toggle may be silently ignored depending on mod load order. Everything else about running both mods together is fine. If you notice a disabled gate still accepting flights, that's this — a proper fix is planned for a future update.

[h2]Optional, No Technical Conflict[/h2]
IPT4 includes its own vehicle route panel, credited to and inspired by the mods below — but unlike the mods in the section above, these do zero Harmony patching, so there's no actual state conflict running them alongside IPT4. Feature sets differ (e.g. TTS, vertical CJK text support), so running the original may still be worth it for you. If you enable both, you may see two overlays at once - just disable whichever one you don't want, either mod's own toggle works:

[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3233229958]Train Display - Updated[/url] (credit: Will)
