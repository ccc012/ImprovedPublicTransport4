[h1]Improved Public Transport 4[/h1]
[b]One mod instead of fifteen.[/b] Real control over every transit line — fleet size, vehicle types, stops, fares — small transit mods folded in so they stop fighting.
[b]Version 4.8.5[/b] · Built for game version 1.21.1-f9

[h1]Чому це існує[/h1]
Витрати на утримання транспорту злетіли до [b]-42 000 000 000[/b] через конфлікт: два моди незалежно керували розміром автопарку кожної лінії, перезаписуючи один одного. Потрібна одна система. Це IPT4.
Одна збірка, один патч на метод, плюс ~10-20 FPS економії (тести: ~50-60 FPS замість ~40-50 FPS при окремих модах).
[hr][/hr]
[h1]Що ви можете з цим зробити[/h1]
[h2]Візьміть під контроль будь-яку лінію[/h2]
Усі типи транспорту: автобус, трамвай, метро, поїзд, корабель, літак, монорейка, такси, екскурсії. Для кожної лінії: [b]встановіть розмір автопарку[/b] або дозвольте розраховувати з бюджету, [b]оберіть тип транспорту[/b], [b]редагуйте індивідуально[/b], [b]оберіть депо[/b].
[h2]Усуньте скупчення транспорту (bunching)[/h2]
Три рівні для кожної лінії: [b]Вимкнено[/b], [b]Обережно[/b] (м'який інтервал), [b]Реалістично[/b] (справжні інтервали). Або режим [b]Експрес[/b] для пропуску порожніх зупинок.
[h2]Встановлюйте власні тарифи[/h2]
Ціна для кожного типу у вкладці [b]Ціни квитків[/b] Економіки, з опціональною [b]політикою день/ніч[/b]. Дешевий транспорт заповнюється, дорогий порожніє.
[h2]Дивіться, що відбувається[/h2]
[b]Панель зупинки[/b] (пасажири, маршрут, наповненість), [b]Train Display[/b] (накладення маршруту в реальному часі, налаштовується), [b]автоколори ліній[/b] для карти, [b]Flight Tracker[/b] для аеропорту.
[h2]Наведіть лад у мережі[/h2]
[b]Масове видалення ліній[/b] за типом, [b]краще розміщення зупинок[/b] (естакади), [b]інструмент вивільнення[/b] для застряглого транспорту.
[h2]Новинки версії 4.8[/h2]
[b]Single Train Track AI[/b] — зарезервована залізниця лише для одного напрямку за раз. [b]Stop Stacker[/b] — другий автобус отримує власне місце замість очікування. [b]Intercity Bus Control[/b] виправлено (DLC-перевірка була ненадійна). [b]Sub-Buildings Tabs[/b] виправлено (рідкісний баг після знесення). Плюс багато-багато інших виправлень — див. GitHub changelog.

[h1]Початок[/h1]
1) Підпишіться на [b]Harmony[/b], 2) Відпишіться від модів вище, 3) Увімкніть IPT4, 4) Натисніть на лінію. Налаштування: [b]Settings → Mod Settings → IPT4[/b]. Тарифи: [b]Economy[/b]. [b]Існуючі збереження працюють[/b].
