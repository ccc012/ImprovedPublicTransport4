[h1]Improved Public Transport 4[/h1]
[b]One mod instead of fifteen.[/b] Real control over every transit line — fleet size, vehicle types, stops, fares — small transit mods folded in so they stop fighting.
[b]Version 4.8.5[/b] · Built for game version 1.21.1-f9

[h1]Чому це існує[/h1]
Витрати на утримання транспорту злетіли до [b]-42 000 000 000[/b]: два моди незалежно керували розміром автопарку, перезаписуючи один одного. Потрібна одна система. Це IPT4.
[hr][/hr]
[h1]Що ви можете з цим зробити[/h1]
[h2]Візьміть під контроль будь-яку лінію[/h2]
Для кожної лінії: [b]встановіть розмір автопарку[/b] або дозвольте розраховувати з бюджету, [b]оберіть тип транспорту[/b], [b]редагуйте індивідуально[/b], [b]оберіть депо[/b].
[h2]Усуньте скупчення транспорту (bunching)[/h2]
Три рівні: [b]Вимкнено[/b], [b]Обережно[/b], [b]Реалістично[/b]. Або [b]Експрес[/b] для пропуску порожніх зупинок.
[h2]Встановлюйте власні тарифи[/h2]
Ціна для кожного типу у [b]Ціни квитків[/b], з опціональною [b]політикою день/ніч[/b].
[h2]Дивіться, що відбувається[/h2]
[b]Панель зупинки[/b], [b]Train Display[/b] (накладення маршруту в реальному часі), [b]автоколори ліній[/b], [b]Flight Tracker[/b].
[h2]Наведіть лад у мережі[/h2]
[b]Масове видалення ліній[/b], [b]краще розміщення зупинок[/b], [b]інструмент вивільнення[/b].
[h2]Новинки версії 4.8[/h2]
[b]Single Train Track AI[/b] — залізниця резервується для одного напрямку. [b]Stop Stacker[/b] — другий автобус отримує власне місце. [b]Intercity Bus Control[/b] виправлено. [b]Sub-Buildings Tabs[/b] виправлено. Плюс інші виправлення — див. GitHub changelog.

[h1]Початок[/h1]
Підпишіться на [b]Harmony[/b], відпишіться від модів вище, увімкніть IPT4, натисніть на лінію. Налаштування: [b]Settings → Mod Settings → IPT4[/b]. Тарифи: [b]Economy[/b]. [b]Існуючі збереження працюють[/b].

[h1]Стабільність[/h1]
