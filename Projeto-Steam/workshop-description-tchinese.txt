[h1]Improved Public Transport 4[/h1]
[b]One mod instead of fifteen.[/b] Real control over every transit line — fleet size, vehicle types, stops, fares — small transit mods folded in so they stop fighting.
[b]Version 4.8.5[/b] · Built for game version 1.21.1-f9

[h1]為什麼需要這個模組[/h1]
交通維護費失控飆升至約 [b]-42,000,000,000[/b]——兩個正常運作的模組各自獨立決定車隊規模並相互覆蓋。解決之道是集中於一處，使用一個系統。這就是 IPT4。
[hr][/hr]
[h1]你能用它做什麼[/h1]
[h2]全面掌控任意路線[/h2]
每條路線都有完整控制面板：[b]自行設定車隊規模[/b]或按預算調整，[b]選擇運行車輛[/b]，[b]單獨編輯車輛[/b]並[b]選擇車庫[/b]。
[h2]修復車輛擠在一起的問題[/h2]
三個級別：[b]已停用[/b]（原版）、[b]謹慎[/b]（溫和間距）、[b]真實[/b]（真實間隔）。或用[b]特快[/b]模式跳過沒有乘客的站點。
[h2]自訂票價[/h2]
在[b]票價[/b]分頁獨立設定每種交通工具價格，可選[b]日間/夜間定價[/b]。價格影響需求。
[h2]掌控全局[/h2]
[b]站點資訊面板[/b]、[b]列車顯示器[/b]（即時路線覆蓋圖）、[b]自動路線顏色和名稱[/b]、[b]航班追蹤器[/b]。
[h2]清理你的網路[/h2]
[b]大量刪除路線[/b]、[b]更好的站點放置[/b]（含高架軌道）、釋放卡住車輛的[b]防卡死工具[/b]。
[h2]4.8 版本新功能[/h2]
[b]單軌列車 AI[/b]——共享單線段一次只保留一個方向。[b]站點堆疊器[/b]——第二輛車獲得獨立停靠位。[b]城際公車控制[/b] DLC 檢查修復。[b]子建築分頁[/b]舊分頁錯誤修復。此外還有錯誤修復和效能最佳化——完整清單見技術更新日誌。

[h1]要求與相容性[/h1]
需要 [b]Harmony[/b] (ID 2040656402)。[b]不相容：[/b]IPT2、IPT3、Transport Lines Manager 或上述模組的獨立副本——遊戲內會警告你。
[hr][/hr]
[h1]語言[/h1]
[b]全部 23 種語言完全翻譯[/b]——每個字串，不僅限選單。跟隨遊戲語言，或在選項中選擇。
[hr][/hr]
[h1]快速入門[/h1]
訂閱 [b]Harmony[/b]，取消訂閱獨立模組，啟用 IPT4，點擊任何路線。選項在 [b]選項 → 模組設定 → IPT4[/b]；票價在 [b]經濟[/b] 面板。[b]現有存檔有效[/b]。
[hr][/hr]
[h1]穩定性[/h1]
穩定頻道。維護費失控錯誤已修復，損壞存檔自動修復。請[b]保留備份存檔[/b]。出現問題請說明[i]你當時在做什麼[/i]並附上：
[code]%LOCALAPPDATA%\Colossal Order\Cities_Skylines\Cities_Data\output_log.txt[/code]
沒有日誌無法診斷。
