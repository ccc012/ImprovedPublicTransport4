[h1]Improved Public Transport 4[/h1]
[b]15개의 모드를 하나로.[/b] 모든 대중교통 노선을 완전히 제어: 차량 수, 차량 종류, 정류장, 요금. 소형 모드를 통합했습니다.
[b]Version 4.8.8[/b] · Built for game version 1.21.1-f9

[h1]이 모드가 존재하는 이유[/h1]
교통 유지비가 [b]-42,000,000,000[/b]까지 치솟았습니다 — 두 모드가 각각 독립적으로 차량 수를 결정하며 서로 덮어썼기 때문입니다. 이 모드는 관리를 중앙 집중화하여 충돌을 해결합니다.
[hr][/hr]
[h1]이 모드로 할 수 있는 것[/h1]
[h2]모든 노선을 직접 관리하세요[/h2]
모든 종류의 노선에 제공: [b]차량 수 관리[/b](수동 또는 예산 기반), [b]운행 차량 선택[/b], [b]개별 편집[/b], [b]차고지 선택[/b].
[h2]차량 뭉침 방지[/h2]
뭉침 방지 3단계: [b]Disabled[/b](바닐라), [b]Prudent[/b](간격 조절), [b]Realistic[/b](실제 배차 간격). [b]Express[/b] 모드는 빈 정류장을 건너뜁니다.
[h2]직접 요금 설정[/h2]
[b]경제[/b] 패널에서 각 교통 수단의 가격을 책정하고 [b]주간/야간 요금제[/b] 옵션 지원. 가격은 수요를 자연스럽게 이끕니다.
[h2]상황 파악[/h2]
[b]정류장 정보[/b](승객, 차량, 혼잡도), [b]차량 노선 패널[/b](실시간 설정 가능한 오버레이), 알아보기 쉬운 [b]자동 노선 색상/이름[/b], [b]공항 항공편 게시판[/b](도착/출발).
[h2]네트워크 정리[/h2]
[b]노선 일괄 삭제[/b](종류별, 확인 포함), [b]고가 정류장 배치[/b], 멈춘 차량을 해제하는 [b]고립 해제 도구[/b].
[h2]4.8.8: 실제 플레이 버그 정리[/h2]
기능 업데이트가 아닙니다 — 아래 수정 사항은 모두 4.8.7을 실제로 플레이하며 무엇이 고장났는지 보고한 결과입니다. [b]차량 경로 탐색[/b] 수정(버스가 정류장을 벗어나 연석에 붙고 교량 바닥판을 뚫고 지나갔습니다. 또한 겹쳐 탑승시키는 패치가 버스를 너무 이른 유턴으로 이끌 수 있었습니다). [b]승객 목적지 오버레이[/b]: 실제 Harmony 패치 충돌을 발견하고 수정했지만, 테스트에서 여전히 아이콘/패널이 확실히 표시되지 않아 [b]기본 비활성, Experimental[/b]로 유지됩니다. [b]예산 관리 체크박스[/b]가 체크하는 즉시 스스로 풀리던 문제를 수정했습니다. [b]차고지 라우팅[/b]: 동시에 두 서비스를 제공하는 건물에서 발생하던 문제 수정. 특정 손상 저장 파일에서 발생하는 실제 바닐라 충돌에 대한 가드를 추가했습니다(우리 버그가 아니라 시뮬레이션 전체가 죽는 것을 막을 뿐입니다). 일부 옵션 이름을 출처 모드 이름 대신 기능을 설명하는 이름으로 변경했습니다(크레딧은 이 페이지와 소스에 유지됩니다). 전체 기술 변경 로그는 아래 GitHub 링크에 있습니다.

[h1]언어[/h1]
게임 언어를 따르거나 옵션에서 선택하세요. 영어와 포르투갈어는 매 릴리스마다 완전히 최신 상태로 유지됩니다. 다른 언어는 일괄 업데이트되어 새로운 텍스트에서 한두 릴리스 늦을 수 있습니다 — 그동안은 자연스럽게 영어로 대체됩니다.

[h1]시작하기[/h1]
[b]Harmony[/b] 구독, 단독 모드 구독 취소, IPT4 활성화. 옵션: [b]설정 → 모드 설정 → Improved Public Transport 4[/b]; 요금: [b]경제[/b] 패널. [b]기존 저장 파일 작동함[/b].

[h1]안정성[/h1]
안정적입니다. 유지비 폭주 버그 근본 수정, 손상 저장 파일 자동 복구. [b]백업 저장 유지[/b] 권장. 문제 발생 시 [i]무엇을 하고 있었는지[/i] 설명하고 첨부:
[code]%LOCALAPPDATA%\Colossal Order\Cities_Skylines\Cities_Data\output_log.txt[/code]
