[h1]Improved Public Transport 4[/h1]
[b]열다섯 모드를 하나로.[/b] 노선 완전 제어: 차량 수/유형, 정류장, 요금. 소규모 모드 통합.
[b]v4.8.8[/b] · 게임 1.21.1-f9용

[h1]존재 이유[/h1]
유지비 [b]-42,000,000,000[/b] 폭증 — 두 모드가 독립적 차량 조절로 충돌. 중앙화로 해결.
[hr][/hr]
[h1]기능[/h1]
[h2]모든 노선 관리[/h2]
모든 유형: [b]차량 제어[/b] (수동/예산), [b]차량 선택[/b], [b]개별 편집[/b], [b]차고지 선택[/b].
[h2]몰림 방지[/h2]
세 단계: [b]사용 안 함[/b] (바닐라), [b]신중[/b] (간격), [b]현실적[/b] (실제 배차). [b]급행[/b]은 빈 정류장 통과.
[h2]요금 직접 설정[/h2]
[b]경제[/b] 패널에서 유형별 요금, [b]주간/야간[/b] 옵션.
[h2]실시간 모니터링[/h2]
[b]정류장 정보[/b] (승객/차량/혼잡), [b]차량 노선 패널[/b], [b]자동 색상/이름[/b], [b]공항 안내판[/b].
[h2]네트워크 정리[/h2]
[b]일괄 삭제[/b] (유형별), [b]고가 정류장[/b], [b]언스투커[/b].
[h2]4.8.8: 실전 버그 수정[/h2]
기능 추가 없음 — 4.8.7 플레이 중 발견분만 수정. [b]차량 경로[/b] (인도 주행/교량 클리핑/조기 유턴), [b]목적지 오버레이[/b] (Harmony 충돌 수정, 아이콘 불안정→[b]기본 끔/실험적[/b]), [b]예산 체크박스[/b] 자동 해제 방지, [b]차고지 경로[/b] (듀얼 서비스), 손상 세이브 바닐라 충돌 가드. 옵션명 기능 위주로 변경 (크레딧 유지). 변경내역 GitHub.
