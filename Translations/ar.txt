CHANGELOG_4_3_3_2 Hardened the bundled Newtonsoft.Json resolver so it always prefers the copy shipped next to this mod instead of returning whichever copy another mod happened to load first (Real Time ships a strong-named v13; CSLModsCommon needs the unsigned v9). Handing our code the wrong build made JsonHelper fail silently and return empty objects, which is what left the framework's own locale sources empty and the language selector showing raw locale ids.
CHANGELOG_4_3_3_3 Bengali, Hindi, Indonesian and Urdu now appear in the mod's language selector. They were already fully translated, but the framework had no locale file for them, so they were unreachable unless the game itself ran in that language.
CHANGELOG_4_3_3_4 Optimized the stop passenger limiter: it resolved the settings object (two dictionary lookups) once per citizen instance inside a loop that runs thousands of times per frame. It is now resolved once per frame.
CHANGELOG_4_3_3_5 Made the mod folder lookup independent of which class implements IUserMod. That coupling had already silently broken translation loading once and the ticket-price icon atlases a second time, each after an unrelated refactor.

CHANGELOG_4_1_5_1 Fixed the real cause of the blank/black Options panel: CSLModsCommon's own UI strings (Version/Changelog/etc.) live in a physical Localization/Common folder next to the DLL that our build never deployed. Now the .csproj deploys that folder, and GetTranslationProgress() no longer throws if it's ever missing again.

CHANGELOG_4_3_7_1 جميع اللغات الثلاث والعشرين في القائمة مترجمة بالكامل الآن. كانت التشيكية والهولندية والسلوفاكية والتايلاندية والتركية متاحة للاختيار دون ملف ترجمة، فتعود إلى الإنجليزية دون تنبيه.
CHANGELOG_4_3_7_2 كان تقدم الترجمة المعروض تحت محدد اللغة يقرأ ملف حالة ثابتًا لم يُعد إنشاءه، لذلك أظهر 76% لست عشرة لغة كانت مكتملة فعليًا.
CHANGELOG_4_3_6_1 تم إصلاح السبب الحقيقي لمصروف النقل العام البالغ حوالي 21.4- مليون: كان حساب الصيانة الأسبوعي في IPT يقسم على سعة مركبة تساوي صفرًا أو غير مدعومة، فيتحول NaN إلى int.MinValue، ويُجمع بعدها لكل مركبة داخل int أخر. القيم غير الصالحة تستخدم الآن قيمة احتياطية أصلية آمنة، ومجاميع الخطوط تستخدم حسابًا بدقة 64 بتًا، والمبالغ الكبيرة الصالحة تُحمل فقط عبر معاملات موجبة محدودة.
CHANGELOG_4_3_6_2 يتم إصلاح الملفات المحفوظة المتأثرة عند التحميل: تُصفّر فقط فترات الدخل أو المصروف السلبية الخاصة بالنقل العام التي تركها هذا الخلل، مع تصحيح المجاميع المقابلة. يبقى التاريخ الاقتصادي السليم وكل الخدمات الأخرى دون مساس.
